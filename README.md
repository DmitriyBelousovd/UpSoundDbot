# Бот для тестового задания UpSound

Telegram-бот для тестового задания UpSound.
Принимает ссылки на треки Яндекс.Музыки и возвращает название трека, артиста и длительность.

## Возможности

- Проверяет формат URL трека Яндекс.Музыки
- Извлекает метаданные со страницы трека
- Возвращает нормализованный ответ с длительностью в формате `MM:SS`
- Корректно обрабатывает невалидные ссылки и сетевые/парсинг-ошибки

## Структура проекта

- `src/main.py` - точка входа приложения
- `src/bot.py` - обработчики Telegram
- `src/services/yandex_music.py` - валидация ссылок и извлечение метаданных
- `src/utils/link_parser.py` - извлечение URL из текста
- `docs/` - чек-листы, архитектура, шаблоны сдачи
- `tests/` - минимальные тесты

## Локальный запуск

1. Установите Python 3.11+
2. Создайте и активируйте виртуальное окружение
3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`
5. Запустите:

```bash
python -m src.main
```

## Тесты

```bash
pytest
```

## Деплой (пример для Render)

1. Отправьте репозиторий в GitHub.
2. Создайте новый Render Web Service из репозитория.
3. Runtime: Python.
4. Команда сборки:

```bash
pip install -r requirements.txt
```

5. Команда запуска:

```bash
python -m src.main
```

6. Добавьте переменные окружения:
   - `BOT_TOKEN`
   - `REQUEST_TIMEOUT_SECONDS=10`
7. Включите авто-пересборку и мониторинг логов.
