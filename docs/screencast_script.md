# Сценарий скринкаста (5-15 минут)

## 0:00-0:45 Введение

- Кратко представить задачу.
- Озвучить ожидаемый результат: название, артист, длительность по ссылке на трек Яндекс.Музыки.

## 0:45-3:00 Подход в Cursor/Claude Code

- Пояснить, как были декомпозированы требования.
- Показать архитектуру и ключевые компоненты.
- Отметить edge-cases: невалидные ссылки, недоступные треки, сетевые сбои.

## 3:00-6:30 Разбор реализации

- `src/bot.py`: обработчики Telegram.
- `src/services/yandex_music.py`: валидация + извлечение метаданных.
- `src/utils/link_parser.py`: извлечение URL.

## 6:30-9:00 Живая демонстрация

- Отправить валидную ссылку на трек и показать успешный ответ.
- Отправить невалидную/неподдерживаемую ссылку и показать корректную обработку ошибки.

## 9:00-10:30 Проверка и надежность

- Показать быстрый прогон тестов (`pytest`).
- Упомянуть стратегию деплоя и окно доступности для проверок (11:00-19:00).

## 10:30-11:30 Финальные замечания

- Кратко подвести итоги по артефактам сдачи.
- Показать Google Docs с открытым доступом и всеми ссылками.
