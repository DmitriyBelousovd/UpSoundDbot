## 2-е задание

### Ссылка на бота
- `https://t.me/<bot_username>`

### Как проверить
1. Открыть бота по ссылке
2. Отправить ссылку на трек:
   - `https://music.yandex.ru/album/<id>/track/<id>`
3. Убедиться, что бот вернул:
   - название
   - артист
   - длительность

### Примеры

- Запрос: `https://music.yandex.ru/album/31085239/track/126040271`
- Ожидаемый формат ответа:
  - Название: `<track_title>`
  - Артист: `<artist_name>`
  - Длительность: `<mm:ss>`

- Запрос: `невалидная ссылка`
- Ожидаемое поведение:
  - Понятная ошибка с просьбой прислать корректную ссылку на трек
