# Чек-лист деплоя и доступности

## Перед деплоем

- [ ] `BOT_TOKEN` создан через BotFather
- [ ] Зависимости установлены
- [ ] `python -m pytest` проходит успешно

## Шаги деплоя в Render

1. Отправить проект в Git-репозиторий
2. В Render создать Worker по конфигу `render.yaml`
3. Задать секретную переменную окружения `BOT_TOKEN`
4. Запустить деплой
5. Открыть логи и проверить запуск бота без исключений

## Проверка после деплоя

- [ ] Открыть `https://t.me/<bot_username>`
- [ ] Выполнить `/start`
- [ ] Отправить валидную ссылку на трек Яндекс.Музыки
- [ ] Отправить невалидную ссылку и проверить сообщение об ошибке
- [ ] Повторно проверить доступность сервиса в окне 11:00-19:00

## Действия при инцидентах

- Если ломается парсинг: вернуть пользователю понятную ошибку и проверить `src/services/yandex_music.py`
- Если растут таймауты: увеличить `REQUEST_TIMEOUT_SECONDS` до 15
- Если worker перезапускается: проверить логи платформы на сетевые ошибки и лимиты
