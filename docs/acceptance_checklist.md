# Тестовое задание UpSound: чек-лист приемки

## Обязательные артефакты

- [ ] Публичный документ Google Docs с открытым доступом на просмотр
- [ ] Рабочая ссылка на Telegram-бота в формате `https://t.me/<bot_username>`
- [ ] Бот принимает ссылку на трек Яндекс.Музыки и возвращает:
  - [ ] Название трека
  - [ ] Артиста
  - [ ] Длительность
- [ ] Скринкаст (5-15 минут) с пояснением подхода к реализации через Cursor/Claude Code

## Надежность и валидация

- [ ] Бот обрабатывает валидные ссылки на треки Яндекс.Музыки
- [ ] Бот отклоняет невалидные или неподдерживаемые ссылки с понятным сообщением
- [ ] Бот корректно обрабатывает недоступные треки и сетевые ошибки
- [ ] Бот доступен для случайных проверок с 11:00 до 19:00

## Формат сдачи

- [ ] Все результаты собраны в одном Google Docs документе
- [ ] Разделы идут в порядке заданий 1/2/3
- [ ] Ссылки на бота и скринкаст открываются без запроса дополнительных прав
