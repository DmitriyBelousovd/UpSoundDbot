# Архитектура бота

## Обзор

Решение использует легковесного Telegram-бота на Python: он обрабатывает входящие сообщения, извлекает URL трека Яндекс.Музыки, получает метаданные страницы и возвращает нормализованную информацию о треке.

## Поток обработки запроса

1. Пользователь отправляет боту сообщение со ссылкой.
2. Бот извлекает URL из текста и валидирует, что это поддерживаемая ссылка на трек Яндекс.Музыки.
3. Сервис метаданных загружает страницу трека и парсит Open Graph/JSON-LD данные.
4. Бот формирует ответ:
   - Название
   - Артист
   - Длительность (`MM:SS`)
5. При любой ошибке бот отправляет понятное сообщение с дальнейшими действиями.

## Компоненты

- `src/main.py`: точка входа.
- `src/bot.py`: обработчики Telegram и форматирование ответов.
- `src/services/yandex_music.py`: валидация URL + получение и парсинг метаданных.
- `src/utils/link_parser.py`: извлечение URL из произвольного текста.
- `src/config.py`: конфигурация через переменные окружения.

## Матрица обработки ошибок

- Невалидный URL -> "Пришлите корректную ссылку на трек Яндекс.Музыки"
- Неподдерживаемый тип страницы (альбом/плейлист/артист) -> "Поддерживаются только ссылки на треки"
- Страница трека недоступна -> "Трек не найден или временно недоступен"
- Таймаут сети -> "Временная сетевая ошибка, попробуйте позже"
- Ошибка парсинга метаданных -> "Не удалось извлечь данные трека"
